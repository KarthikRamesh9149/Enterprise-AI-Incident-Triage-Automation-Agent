# Observability

The admin dashboard computes local product metrics from stored records:

- Incident counts.
- Open incident counts.
- Tool call counts.
- Tool failure rate.
- Average tool latency.
- Agent runs.
- Pending approvals.
- Security event counts.

Agent trace steps store node name, status, summary, latency, error, and retry count. Audit logs store user, action, resource, metadata, and timestamp.
